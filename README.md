# Awesome Pizza 
Sistema di gestione ordini per la pizzeria Awesome Pizza, sviluppato con Spring Boot e Java 21.
Il progetto è stato realizzato seguendo queste fasi:

1. sviluppo iniziale delle REST API
2. testing tramite Postman
3. implementazione test automatici con JUnit e Mockito
4. sviluppo interfaccia grafica tramite Thymeleaf

## Funzionalità principali
-Creazione ordini pizza
-Gestione stato ordini
-Visualizzazione coda ordini
-Aggiornamento stato da parte del pizzaiolo
-Tracciamento ordine tramite codice univoco
-Interfaccia grafica per gestione pizze e ordini

## Architettura
-MVC
-REST API
-CRUD con Thymeleaf
-MySQL / DBeaver
